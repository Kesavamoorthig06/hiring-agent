How it works

From PDF to a plan, in four steps.

The same pipeline the open-source project uses, wrapped so you can run it on your own resume.

  1. 01

    Read

    Your PDF becomes clean text, then each section (work, projects, skills, education) is parsed on its own.

  2. 02

    Check signals

    If your resume links a GitHub profile, public activity is pulled in as supporting evidence.

  3. 03

    Score

    Five rubric categories, with evidence for each score, plus bonus points and deductions.

  4. 04

    Improve

    Gemini turns the findings into prioritized fixes and rewrites. Then you chat to work through them.
